# tg-gift-tracker

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Бот для маркета подарков Telegram. Воркер (юзербот на Telethon) снимает цены, бот на aiogram показывает дешёвые лоты и историю владельцев и шлёт алерты о падении цен. Только чтение: без покупок и переводов. Воркер и бот работают в одном процессе (`bot.py`) и делят одну SQLite-базу.

## Что умеет бот

- 🔥 **Дешёвые сейчас**: самые дешёвые лоты по всем коллекциям.
- 🗂 **Коллекции**: нижняя цена и лоты. Зелёная кнопка «Открыть» ведёт на `t.me/nft/<slug>`, покупает человек сам.
- 👤 **Владельцы**: текущий, первый получатель и отправитель (если Telegram их отдаёт) и история смен с момента, как бот увидел лот.
- 🔔 **Подписки** на коллекции: алерты `floor_drop` (упала нижняя цена), `price_drop` (подешевел лот), `new_listing` (новый лот).
- Пользователи из `ADMIN_IDS` получают все события, включая `owner_change`.
- Цвета кнопок: зелёная «Открыть», синие «Следить» и «Показать лоты», красные «Не следить» и «❌», остальные обычные.

## Демо: посмотреть дизайн без юзербота

Нужны только `bot.py`, `schema.py`, `demo_bot.py` и токен **тестового** бота (создай нового у @BotFather: два процесса на одном токене конфликтуют).

```bash
pip install aiogram aiosqlite
export BOT_TOKEN=...
python demo_bot.py
```

Бот работает на выдуманных данных: 15 коллекций, лоты, история владельцев, подписки. Команда `/alerts` присылает примеры алертов. Данные живут в памяти и сбрасываются при перезапуске. На Railway: отдельный сервис с переменной `BOT_TOKEN` и Start command `python demo_bot.py`.

## Запуск с телефона

**1. Ключи.** `API_ID` и `API_HASH` с https://my.telegram.org (лучше на отдельном аккаунте), `BOT_TOKEN` у @BotFather.

**2. Сессия юзербота (один раз, в Termux).**

```bash
pkg install python git
pip install -U telethon aiosqlite
export TG_API_ID=... TG_API_HASH=...
python gift_watcher.py login
```

Команда напечатает `TG_STRING_SESSION`. Это ключ от аккаунта: никому не показывай и в репозиторий не клади.

**3. Railway.**

1. New Project → Deploy from GitHub repo.
2. Variables: `TG_API_ID`, `TG_API_HASH`, `TG_STRING_SESSION`, `BOT_TOKEN`, `ADMIN_IDS` (твой Telegram id), `DB_PATH=/data/gifts.db`.
3. Add Volume с путём монтирования `/data`. Без него база (подписки и история владельцев) пропадёт при каждом деплое.
4. Start command: `python bot.py` (Procfile уже есть).
5. Открой бота и нажми `/start`. Первые минуты воркер делает снимок маркета и событий не создаёт.

## Переменные окружения

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `TG_API_ID`, `TG_API_HASH` | нет | ключи с my.telegram.org |
| `TG_STRING_SESSION` | нет | строка сессии из `login` |
| `BOT_TOKEN` | нет | токен бота |
| `ADMIN_IDS` | пусто | id через запятую: получают все события |
| `DB_PATH` | `gifts.db` | путь к базе |
| `POLL_SECONDS` | 60 | пауза между циклами воркера |
| `TOP_N` | 20 | сколько дешёвых лотов брать по коллекции |
| `MIN_DROP_PCT` | 5 | порог падения цены для события, % |
| `REQUEST_DELAY` | 1.5 | пауза между запросами к Telegram, лучше не уменьшать |
| `DEEP_EVERY` | 10 | раз в N циклов перечитывать все коллекции с лотами |
| `WATCH_GIFT_IDS` | пусто | id коллекций (через запятую), которые опрашивать каждый цикл |
| `ALERT_POLL` | 5 | как часто бот проверяет новые события, сек |
| `ICONS` | пусто | премиум-иконки: `роль:ID` через запятую (см. ниже) |

## Премиум-иконки

Кнопки и заголовки алертов могут показывать премиум-эмодзи. По документации Bot API это работает, если у владельца бота (аккаунта, который создал его в @BotFather) есть Telegram Premium, либо бот купил дополнительные юзернеймы на Fragment.

1. Запусти демо-бота (`demo_bot.py`) и пришли ему сообщение с премиум-эмодзи: он ответит их ID.
2. Задай переменную `ICONS`, пары `роль:ID` через запятую:

```bash
export ICONS="open:5368324170671202286,follow:5368324170671202286"
```

3. Перезапусти бота.

Роли: `hot`, `cols`, `subs` (кнопки меню), `open` (Открыть), `owners` (Владельцы), `follow`, `unfollow`, `back` (Назад и Меню), а также `floor_drop`, `price_drop`, `new_listing`, `owner_change` (эмодзи в начале алерта). У кнопки с иконкой обычный эмодзи в начале текста убирается сам. Если иконки не появились, проверь Premium у владельца бота или удали `ICONS`.

## Безопасность

- Юзербот автоматизирует обычный аккаунт: используй отдельный и не занижай `REQUEST_DELAY`, иначе возможны ограничения.
- `*.session`, `.env` и `*.db` в `.gitignore`. Строку сессии храни только в переменных Railway.
